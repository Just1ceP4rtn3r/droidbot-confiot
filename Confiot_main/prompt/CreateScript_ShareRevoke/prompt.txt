**Objective:**

Your task is to process a series of operations on Android UI elements. For each operation, you will be given the action to perform and the target `view` object. Your sole responsibility is to format this information into a specific JSON structure.

**Input:**

The input will consist of two parts for each operation:

1.  **`operation`**: A string indicating the action to be performed on the `view`.
2.  **`view` structure**: A JSON object representing the Android view element to be acted upon.

**Available Operations:**

You must map the input `operation` string to one of the following `event_type` values in the output JSON:

  * `exit`: Corresponds to `KEY_ExitEvent`
  * `click`: Corresponds to `KEY_TouchEvent`
  * `long_click`: Corresponds to `KEY_LongTouchEvent`
  * `swipe`: Corresponds to `KEY_SwipeEvent`
  * `scroll`: Corresponds to `KEY_ScrollEvent`
  * `set_text`: Corresponds to `KEY_SetTextEvent`
  * `intent`: Corresponds to `KEY_IntentEvent`
  * `spawn`: Corresponds to `KEY_SpawnEvent`
  * `kill_app`: Corresponds to `KEY_KillAppEvent`

**Output Format:**

You must generate a JSON array of objects. Each object represents a single event and must strictly adhere to the following structure. Do not add any extra explanations or introductory text.

**JSON Output Structure:**

**Key Formatting Rules:**

1.  The `event_type` must be one of the specified values (e.g., `click`, `set_text`).
2.  The fields within the view object must be populated strictly according to the schema in the JSON Output Structure. If the input data does not provide a value for a specific field, set it to null.
3.  For the `set_text` operation, you must include a top-level `text` field in the JSON object, containing the text to be set.
4.  For all other operations, the `text` field should be omitted or set to `null`.
